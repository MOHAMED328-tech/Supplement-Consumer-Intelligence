# Supplement Consumer Intelligence

Analyzing consumers, supplement products, and sales data to identify
consumer preferences, product performance, and market opportunities
for a supplement brand.

**Tools:** Python -> SQL -> Power BI
**Program:** DEPI, Data Analyst track

## Data Sources
| Type | Source | Notes |
|---|---|---|
| Consumer | NHANES (CDC) | U.S. survey data |
| Product | NIH Dietary Supplement Label Database | Manufacturer-reported labels |
| Sales | Synthetic dataset | Generated with Python, built on real categories |

> Sales data is synthetic because real supplement sales data is not
> publicly available. Findings demonstrate the method, not real market results.
